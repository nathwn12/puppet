# Repository policy

- One fact has one home. Cite or generate it; never retype it.
- This file states policy only. Facts, versions, paths, and procedure belong in specs, configs, or generated docs.
- Change control runs in order: plan, spec, decision record, code.
- Superseded decisions stay visible and are marked, never silently removed.
- A worker changes only files inside its own seam.
- A claim without a command is unverified. A check that never failed proves nothing.
- Report the command and its exit beside every result.
- Phase 1 is report-only; strict mode is earned by a clean report, per repository.
- Archives are frozen and are not migration targets.
